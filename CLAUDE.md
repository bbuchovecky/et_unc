# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Research code for quantifying evapotranspiration (ET) uncertainty. ET is binned in a 2-D space of climatological leaf area index (LAI, y-axis) and aridity index (AI = Rn / L·P, x-axis), so observational products (ILAMB and gridded ET products), ERA5, CMIP6 models, CESM2 ensembles (FHIST PPE "fppe", offline IHIST PPE "ippe", LENS2 "lens"), TRENDY DGVMs and PLUMBER2 flux towers can be compared bin by bin.

Runs on NCAR's glade (Derecho/Casper). Data and outputs live outside the repo:
- Inputs: `/glade/campaign/univ/uwas0155/` (ILAMB and gridded obs in `obs/`, the CESM2 PPEs in `ppe/`). This is shared campaign storage, so don't write there unless asked. LENS2 and ERA5 are read from GDEX, the PLUMBER2 tower files from `plumber_root`.
- TRENDY (GCB2025) output and its forcing (`crujra3/`, `Radiation/`): `/glade/campaign/univ/uwas0155/trendyv14-gcb2025/` (`TRENDY_ROOT`, shared campaign storage).
- CMIP6 catalogs: `/glade/derecho/scratch/bbuchovecky/cmip_intake_esgf_fetch/catalogs/` (`cmip6_bin.csv`: evspsbl, lai, pr and radiative fluxes, `cfg.CMIP_CATALOG`; `cmip6_fx_glade.csv`: sftlf, `cfg.CMIP_FX_CATALOG`). They, and about 2/3 of the file paths in `cmip6_bin.csv`, are on purgeable Derecho scratch. Moving them only needs `cmip_fetch_root` changed in `config/paths.yml`.
- Outputs: `/glade/work/bbuchovecky/et_unc/proc` (netCDF, `PROC_ROOT`) and `/glade/work/bbuchovecky/et_unc/fig` (figures, `FIG_ROOT`), both laid out as `<root>/<id>/<family>/<kind>/` with `<id>` a run or prep ID (see Runs and Output folders below); bin edges in `proc/<run_id>/all/edges/`. The repo's `fig` is a symlink to `FIG_ROOT`, ignored by git, so figures are not tracked. Figures made for a collaborator are copied into the repo's `for/<person>/` (tracked; new ones in the same `<id>/<family>/<kind>/` layout, e.g. `for/<person>/<run_id>/obs/clim/`; the existing ones, in `for/aswann/`, are in the former `<family>/<kind>/<period>/` layout).
- Every path above is set in `config/paths.yml` (gitignored, machine-specific; `config/paths.example.yml` is the committed template, `ETUNC_PATHS` names another file), read by `etunc/config.py`. The loaders (`load/cesm.py`, `load/era5.py`, ...) take their roots from `etunc.config`.

## Commands

The Python env is the pixi env `etunc`, defined in `pyproject.toml` (`[tool.pixi.*]`, exact versions in `pixi.lock`) with the repo installed editable. It is detached to `/glade/work/bbuchovecky/pixi/envs/etunc-<hash>/envs/default`. Don't hardcode that path; use `pixi run` (pixi is at `~/.pixi/bin/pixi`). `pixi run` finds the manifest by searching up from the current directory, so outside the repo (e.g. PBS jobs) pass `--manifest-path <repo>/pyproject.toml`, as `scripts/run_logged.sh` does. Ad-hoc commands (`pixi run python ...`) run in the caller's directory, while defined tasks (`pixi run test`, `prep-obs`, …) run in the repo root. Every `pixi run` first checks the env against `pixi.lock`: if the manifest was edited, it re-solves, rewrites `pixi.lock` and updates the env before running. Use `--frozen` (install the lock as-is) or `--locked` (fail if the lock is stale) to prevent that. Dependencies are changed with `pixi add` or by editing the manifest, and the updated `pixi.lock` is committed with them. The env has xarray, xesmf, regionmask, cartopy and dask-jobqueue, but not ILAMB (`etunc.grid.cell_area` is a bit-identical port of `ilamblib.CellAreas`). The notebooks run on the `etunc` Jupyter kernel. `envs/` holds two conda envs outside pixi: `lftp.yml` (lftp for `scripts/download/download_{gleam,pml,sith}.sh`) and `openet.yml` (Earth Engine, for exploring OpenET; no current notebook uses it). The repo is self-contained: don't add dependencies on the user's other packages (e.g. xclimate) or on modules from their other projects.

The scripts in `scripts/` take no CLI arguments and import only the `etunc` package, never each other. They are configured by module-level constants at the top of each file (`VARIABLES`, `BIN_FAMILIES`, …); the settings that change results are in `config/pipeline.yml` (sections `prep`: `time_slice`, `target_res`, `min_years`, `min_annual_et`, `lat_bnds`, `na_thresh`, `lf_thresh`, and each family's products, models and members in `prep.<family>`: `obs.ilamb_products`/`gridded_et_products`, `era5.lai_product`, `cmip.source_ids`/`omit_source_ids`/`default_members`/`member_ids`, `lens.members`, `fppe`/`ippe.members`/`drop_outliers`, `trendy.experiments`/`models`/`omit_models`; `binning`: `families`, `bin_variable`, `area_weighted`, `n_xbins`/`n_ybins`, `signif_*`; `plotting`: `dpi`, `hist_bins`), exposed by `etunc.config` as `TIME_SLICE`, `TARGET_RES`, …, `N_XBINS`/`N_YBINS`, and `<FAMILY>_<KEY>` for the family settings (`OBS_ILAMB_PRODUCTS`, `CMIP_MEMBER_IDS`, `TRENDY_EXPERIMENTS`, …), which each prep script assigns to its own constants (`ILAMB_PRODUCTS = cfg.OBS_ILAMB_PRODUCTS`). Each `main()` starts with `cfg.summarize()`, `cfg.register_run()` and `cfg.summarize_settings(globals())`, so the log records every setting and `config/runs.csv` the run. Output folders come from `etunc.config`. The download scripts are in `scripts/download/`.

## Architecture

Layout: `etunc/` (library), `scripts/` (runnable pipelines and analyses; `scripts/download/`, with `trendy/`), `docs/binning-workflow.md` (the pipeline step by step), `docs/obs-availability.md` (obs coverage), `notebooks/`, `tests/`, `envs/` (conda envs outside pixi: `openet`, `lftp`), `for/` (figures shared with collaborators), `fig`, `proc`, `logs` (symlinks to `FIG_ROOT`, `PROC_ROOT` and `WORK_ROOT/logs`, untracked). README.md is a short overview for reproducing the results.

**The binning pipeline** is documented step by step in `docs/binning-workflow.md`, and every family runs the same numbered steps, written out in the script's `main()` as one or two calls per step to small single-purpose library functions (no wrapper hides several steps):
- `scripts/prep_{obs,era5,cmip,lens,fppe,ippe}.py`, steps 1-11: (1-2) raw monthly native fields over `TIME_SLICE`; (3) ET, P, Rn to W/m2; (4) annual means over complete years (`temporal.aggregate(da, "year")`: ET/P/Rn need 12 valid months, a missing LAI month counts as 0); (5) native land mask without Greenland/Iceland (`grid.mask_to_land` with `landne_mask` for ILAMB and gridded obs (also the LAI of prep_era5), `landfrac_mask` of LANDFRAC/sftlf for ERA5, CMIP6 and CESM); (6) ET outlier filter `binning.drop_et_outliers` (annual ET < `MIN_ANNUAL_ET`); (7) conservative regridding (`bounded_conservative_regridder`, `regrid_with_na_thresh` with `NA_THRESH`, `on_grid`); (8) `LAT_BNDS`; (9) complete years shared by the four products (`temporal.shared_years`, ≥ `MIN_YEARS`); (10) climatological LAI, P, Rn over those years (`temporal.aggregate(da, "clim")`); (11) AI = Rn/P (`edges.compute_aridity_index`). Saved as `PROC_ROOT/<prep_id>/<family>/inputs/<family>.inputs.<prep_id>.nc` (`cfg.inputs_path`): `et (member, year, lat, lon)`, `lai`, `pr`, `rn`, `ai (member, lat, lon)`, with a `source` coord on `member`. A source is an obs (ET, LAI, P, Rn) product combination of ILAMB and gridded products (prep_obs, `prep.obs`; with `<v>_product`, `n_years`, `time_period` coords), ERA5 ET, P and Rn with the ILAMB LAI `prep.era5.lai_product` (prep_era5; one source, `lai_product` coord), a CMIP6 model (prep_cmip; member = "<source_id>.<member_id>", `member_id` coord; `prep.cmip.default_members: top` is one member per model), a LENS2/FHIST PPE/IHIST PPE member, or a TRENDY model (prep_trendy; one member per model). The scripts differ only in steps 1, 3 and 5 (prep_ippe: offline CLM, so P = RAIN + SNOW and Rn = FSA - FIRA from "lnd"). Step 11b always saves the annual evaporation ratio `et_pr (member, year, lat, lon)` (`binning.evaporation_ratio`), which the bin scripts bin instead of ET in a run with `binning.bin_variable: et_pr` (default `et`; outputs `<family>.et_pr[_clim].qbin_*`).
- `scripts/prep_trendy.py`, steps 1-11 for the TRENDY DGVMs of each experiment of `prep.trendy.experiments` (S2: climate + CO2, S3: + land use change; default [S3]), each saved as the family `trendy_s2`/`trendy_s3`: ET is `evapotrans`, P is the CRU-JRA precipitation forcing and Rn the ERA5 net radiation (`msnswrf + msnlwrf`, ERA5 LANDFRAC mask), each one field for every model and experiment (steps 1-8 run once before the experiment loop), so the AI is the same for every model; Natural Earth land mask for the model fields, LAI NaN on land set to 0, `prep.trendy.omit_models` (CARDAMOM: 2003-2024 only; LPJml, LPJwsl, LPX-Bern, VISIT: implausible LAI; ED: ET = 0 in high northern latitudes). Every `trendy_*` family in `binning.families` must have its experiment in `prep.trendy.experiments` (checked by `etunc.config`). `trendy_s3` is in `cfg.FAMILIES`, so it enters the common area mask and the pooled_all edges (trendy_s2 does not).
- `scripts/make_edges.py`, steps 12-13: each family's own valid area (`grid.valid_area`) and their intersection (`grid.common_area`, which reports the gridcells and km2 each family loses), saved at `cfg.area_mask_path`; LAI/AI quantile edges on the common area, "pooled_all" with hierarchical weights (`edges.hierarchical_weights`: each family, each group of variants within a family, each source within a group and each member within a source weighs equally) and "pooled_<family>", saved at `edges.edges_path`. Weighted quantiles use `np.quantile(weights=, method="inverted_cdf")`.
- `scripts/bin_all.py`, step 14: for every family in `BIN_FAMILIES`, `binning.bin_stats(member_dim="member", mask=common area)` with both edge sets, per member and with each source's members pooled; with `cfg.AREA_WEIGHTED`, the bin statistics are weighted by each gridcell's land area (`bin_stats(weights=grid.land_area)`, outputs tagged `.area_weighted`, same edges); family-specific outputs (obs spread across ET products, LENS2 members pooled) in a labelled section.
- `scripts/bin_all_clim.py`, step 14 with climatological ET: as `bin_all.py`, but each member's ET is first averaged over `year` (`temporal.aggregate(et, "clim")`, NaN years skipped), so each gridcell is one sample. Outputs are named `<family>.et_clim[.area_weighted].qbin_*`.
- `scripts/bin_area.py`, step 14 for land area: each gridcell of the common area, binned by its member's climatological LAI and AI, with its land area as the value (`grid.land_area`: target-grid cell area times fractional Natural Earth land, one field for every family, since obs have no land fraction). Bin total = `mean` x `count` of `bin_stats`; sources average their members. Outputs `<family>.land_area.qbin_*` (`land_area` km2, `land_area_frac`, `n_cells`).
- `scripts/bin_plumber.py`, step 14 for the PLUMBER2 flux towers (`cfg.PLUMBER_ROOT`): each tower's annual mean Qle over its longest run of consecutive complete years in `TIME_SLICE` (≥ `MIN_CONSECUTIVE_YEARS`, after the step 6 filter), binned by the obs climatological LAI and AI at the nearest gridcell, once per (LAI, P, Rn) product set, with the `pooled_all` and `pooled_obs` edges; towers are not masked by the common area. Its tower inputs are saved under the `PREP_ID` (`cfg.inputs_path("plumber")`). `scripts/bin_plumber_clim.py` reads them and bins each tower's climatological ET (one sample per tower). Outputs `plumber.et[_clim].qbin_*`.

**Analyses and diagnostics outside the pipeline**, run by hand (not by `scripts/run_all.sh`; `regress_lai_aridity.py`, `decompose_state_function.py` and `gridded_state_function_decomp.py` need the step 14 outputs):
- `scripts/make_mask.py`: common valid-data mask of the obs products (monthly fields on a common grid, read with `il.load_ilamb` and `lo.load_obs_regridded`). No pipeline step reads it.
- `scripts/diagnose_obs.py`: coverage of every obs product of ET, LAI, P and Rn (ILAMB, the gridded ET products, CLARA-A3 Rn and NOAA NCEI AVHRR and VIIRS LAI), each variable with the same diagnostics (`docs/obs-availability.md`): land area covered on the native and target grids, native coverage maps (valid months, valid years under the step 4 rule, seasonal gaps), valid land fraction by latitude, regional timeseries, target-grid climatologies with the differences of every pair of products (steps 4-8 and 10 of prep_obs.py), and land-area weighted histograms with `QUANTILES`. Each product is read once and reduced lazily, so 0.1 deg records are never held in memory. Its `PREP_ID` constant is required and fixes the inputs: `TIME_SLICE`, `TARGET_RES`, `LAT_BNDS`, `NA_THRESH`, `MIN_ANNUAL_ET` are the prep settings registered under it in `config/runs.csv` (`cfg.prep_settings`), not the current config. Outputs in `FIG_ROOT/<prep_id>/obs/coverage/` and a CSV per variable in `PROC_ROOT/<prep_id>/obs/coverage/`.
- `scripts/compare_rn.py`: the evidence for the Rn of prep_trendy.py. Downward shortwave (ERA5 `msdwswrf`, CERES `rsds`, CRU-JRA as the median `rsds` of `RSDS_MODELS`, since `crujra3/` has no shortwave), downward longwave (ERA5, CERES `rlds`, CRU-JRA `dlwrf`) and Rn (ERA5, CERES), each through steps 4-8 and 10 on Natural Earth land; every pair compared by band (bias, RMSE, pattern r) and by the interannual r of the land means. Its `PREP_ID` constant is required and fixes the inputs: `TIME_SLICE`, `TARGET_RES`, `LAT_BNDS`, `NA_THRESH` are the prep settings registered under it in `config/runs.csv` (`cfg.prep_settings`), not the current config. Outputs in `PROC_ROOT/<prep_id>/trendy_<experiment>/radiation/` (CSV, climatologies) and `FIG_ROOT/<prep_id>/trendy_<experiment>/radiation/`.
- `scripts/regress_lai_aridity.py`: per member, OLS of ET on climatological LAI and AI (`regression.lai_ai_regression`: R² of ET ~ LAI, ~ AI, ~ LAI + AI and its unique/shared partition) on the samples of `bin_all.py` and `bin_all_clim.py`, with the η² of the bins (`binning.between_bin_fraction`) for comparison. Saved at `PROC_ROOT/<run_id>/<family>/regress/`.
- `scripts/decompose_state_function.py`: state, function and interaction decomposition of the area-mean ET (`etunc.decomposition`), each dataset minus an obs reference. From the land-area weighted `pooled_all` outputs of `bin_all_clim.py` (a run with `binning.area_weighted: true` and `bin_variable: et`, e.g. `config/runs/aw_bins15.yml`, which the script checks; its `RUN_ID` constant (or `ETUNC_RUN_ID`) is required and fixes the inputs and settings, which are those registered under it in `config/runs.csv` (`cfg.run_settings`), not the current config; `EDGES = "pooled_all"`), p = `sum_w` / Σ `sum_w` (occupancy) and f = `mean` of each member, so E = Σ p f is the area-mean ET over the common area. Scalar quantities only: on the common support S (bins with ET in m and r), the counterfactual means E_xy = Σ_S p_x f_y (E_rr, E_rm, E_mr, E_mm; x the state, y the function), FUNCTION = E_rm − E_rr, STATE = E_mr − E_rr, INTERACTION = E_mm − E_rm − E_mr + E_rr (sum E_mm − E_rr), the full-domain E_m, E_r and the off-support occupancy OFF_SUPPORT_m/_r, for every member and each `<family>_pooled` (each group of variants weighted once, `FAMILY_POOL_WEIGHTING`) of cfg.FAMILIES without obs plus `TRENDY_FAMILIES` (trendy_s2 optional), against each obs source and `obs_pooled` (`OBS_POOL_WEIGHTING = "variant"`); the obs spread; the range across obs references by product axis; the variance partition of E_mm − E_rr across the groups of variants of each family (Var(E_mm) and Var(E_rr) alongside, equal to it and 0 when the support is complete); the state shift (`decomposition.state_shift`: LAND_SHIFT = Σ_b |p_m − p_r| / 2, the land in other bins than obs, next to STATE split into STATE_GAINS and STATE_LOSSES from the bins with more and less land); the bin-count sensitivity (last; across the runs of `config/runs.csv` that differ only in `n_xbins`/`n_ybins`; `scripts/run_decomp.sh` runs every `aw_bins*.yml`). The obs product combinations are read from the `<axis>_product` coords (`OBS_PRODUCT_AXES`), so adding obs LAI/P/Rn products needs no change to it: rerun the pipeline, then it. Saved at `PROC_ROOT/<run_id>/all/decomp/` (with the cross-bin summary of the registered runs that differ only in the bin counts).
- `scripts/gridded_state_function_decomp.py`: the decomposition of `decompose_state_function.py` mapped to the lat/lon grid (`decomposition.decompose_gridded`; same `RUN_ID`/`ETUNC_RUN_ID`, inputs and checks, plus the binning inputs of the run's PREP_ID). Each gridcell takes the bin means at its own bins in m and r (`binning.bin_index`, the assignment rule of `bin_stats`): E_xy(i) = f_y(b_x(i)) (0 off the common support), STATE(i) = f_r(b_m) − f_r(b_r), FUNCTION(i) = f_m(b_r) − f_r(b_r), INTERACTION(i), and WITHIN(i) = (e_m − E_mm) − (e_r − E_rr), so DIFF = e_m − e_r = STATE + FUNCTION + INTERACTION + WITHIN at every gridcell. obs_pooled and `<family>_pooled` are mixtures of their members' bin maps with the pool weights, so the land-area mean of every map equals the scalar of `decompose` (the script checks this and that the bin maps reproduce each member's occupancy, and raises otherwise). Every member and pooled family (and each obs source) against each obs source and `obs_pooled`, one netCDF per family (`PROC_ROOT/<run_id>/all/decomp/all.et_clim.decomp_gridded.qbin_pooled_all.<family>.<run_id>.nc`, (dataset, obs_reference, lat, lon), float32); figures vs `obs_pooled` only: the pooled family's maps, the std across groups of variants, and every member's map of each term.

**Load modules are as simple as possible:** each `load_native` does step 1 only and returns raw monthly fields on the native grid, in native units, with lon in [-180, 180] and lat ascending (`format_grid`): `il.load_native(variable, product, time_slice)` (DataArray, fill values NaN), `le.load_native(codes, time_slice)` ({code: DataArray}), `cmip.load_native(loader, sid, members, time_slice, variables=, experiment_id=)` ({variable: (member, time, lat, lon)} with `member_id`), `lc.load_native("lens"|"fppe"|"ippe", members, time_slice, variables={CESM variable: gcomp})`. `lt.load_native(model, experiment, time_slice, variables)` ({variable: (time, lat, lon)}, TRENDY; every time axis is rebuilt as monthly ending in Dec 2024, `lt.LAST_MONTH`), and `lt.load_forcing(variable, time_slice)` (6-hourly forcing shared by every model, as monthly values: `lt.FORCING` lists `pre` (CRU-JRA precipitation, summed to mm/month), `dlwrf` (CRU-JRA downward longwave) and `fd` (`Radiation/` diffuse fraction of the downward shortwave), the latter two averaged). The gridded obs products are read with `lo.load_obs` (lazy, per-year files). `le/cmip/lc.load_land_fraction` return (land fraction [0-1], native grid with cell edges). Monthly regridded loaders for `make_mask.py`: `il.load_ilamb`, `lo.load_obs_regridded`.

**`etunc.load.cmip.CMIPESGFLoader`** reads a catalog CSV produced by the external `cmip-intake-esgf-fetch` tool. It handles model, member and variable availability and loading; model and member selection for `prep_cmip.py` is `cmip.available_members`/`select_members`/`sftlf_files`.

**`etunc/grid.py`** (imported as `rg`) holds the shared regridding utilities. `rg.target_grid(res)` is the only source of target grids: the two standard ones, 0.5° and 1° (`rg.RESOLUTIONS`, named by `rg.grid_tag`), and any other spacing that divides 180. All are global, lon in [-180, 180], lat ascending, with `lat_b`/`lon_b` edges. Never build a target grid by hand. Regridders: `conservative_regridder` (cached, regular 1-D sources), `bounded_conservative_regridder` (cached, any 1-D source such as Gaussian grids, edges from CF bounds or midpoints), `make_regridder` (any method). `regrid_with_na_thresh` applies a conservative regridder skipping NaN and keeps coords such as `member_id`; `on_grid` snaps to the exact target coords (it no longer cuts `LAT_BNDS`).

**`etunc/load/obs.py`** (imported as `lo`) loads gridded obs products (ET: GLEAM v4.3, PML-V2.2, SiTHv2; radiation: CLARA-A3 "clara", not yet used by prep_obs.py since its shortwave is missing in low-sun months; LAI: the NOAA NCEI record (obs4MIPs, 0.05°), one product per sensor, AVHRR v5 "avhrr" (1981-06 to 2013-12, Sep-Dec 1994 missing; not the ILAMB AVHRR product) and VIIRS v1 "viirs" (2014-01 to 2024-12), joined by `load_ncei_lai` with a `sensor` coord and the switch in its attrs, not yet used by prep_obs.py; all in `/glade/campaign/univ/uwas0155/obs/`) into one lazy DataArray with `load_obs(dataset, var, time_slice, version=, freq=)`. `load_obs_regridded(dataset, var, time_slice, res)` conservatively regrids each time step in memory. Each product is an `ObsDataset` entry (path template, versions, frequencies, coord names), so a new product is added with `register_dataset`. Monthly and yearly ET files hold totals (mm/month, mm/year); `etunc.units.accumulation_to_flux` converts them to kg m-2 s-1. CLARA-A3 files hold monthly mean fluxes (W m-2). **`etunc/load/cesm.py`** (`lc`) loads the CESM2 ensembles from the tseries archives (`load_ppe("fppe"|"ippe", ...)`, members in parallel threads; `load_cesm2le`; `load_grid`; `ppe_member_name`). **`etunc/load/era5.py`** (`le`) loads ERA5 monthly means from GDEX and the ERA5 grid file. **`etunc/dask_cluster.py`** (`dc`) starts and stops a PBS dask cluster on Casper or Derecho for the notebooks.

**`etunc/variants.py`** groups closely related sources so each group counts once in every mean, std and weight across a family: cmip by base model (`group_model_variants`, e.g. CESM2 + CESM2-WACCM + ...), obs by ET product version (`OBS_ET_PRODUCT_GROUPS`: GLEAMv4.3a/b, PMLv2.2a_MODIS/c; GLEAMv3.3a apart), with the same LAI, P and Rn; every other family one group per source. `group_means(da, family, dim)` is nested (members of a source, then sources of a group, NaN skipped at each level), then mean/std across `group`. Used by `edges.hierarchical_weights`, `binning.ensemble_spread`/`et_product_spread`, `plotting.save_ensemble_map`/`plot_bin_summary`, `decompose_state_function.py` (with `decomposition.source_weights(..., "variant", groups=)`) and the notebooks `for-abby`/`variance-metric-plots`. Ranges (max − min) and the `sources_pooled` outputs stay per source.

## Conventions that matter

- **Binning semantics:** every (year, gridcell) annual-mean ET sample is binned by that gridcell's climatological LAI and AI of the same member (`bin_all_clim.py`: one climatological ET sample per gridcell). `bin_stats` broadcasts the (lat, lon) LAI and AI fields over `year` (and `member`).
- **Grid alignment:** inputs must share coordinates exactly. `bin_stats` uses `xr.align(join="exact")` and `check_same_grid` raises an error instead of reindexing silently; `mask_to_land` checks the land mask's grid.
- **Evaporation ratio (`BIN_VARIABLE = "et_pr"`):** annual ET_y / P_y with the same year, product and source of P as the AI's P (each obs combination's own P product); NaN where P <= 0. The clim variant (`bin_*_clim.py`) is the mean of the annual ratios. PLUMBER2 towers use the annual P of each product set's `pr_product` over `TIME_SLICE` (`bin_plumber.py`). Edges and common area mask are those of ET.
- **Duplicate quantile edges** (from many LAI = 0 values) are kept on purpose. `searchsorted(side="right")` puts tied values in the *last* duplicate bin, which leaves zero-width empty bins that `drop_zero_width_bins` removes. Out-of-range values are clipped into the edge bins.
- **Output layout:** `bin_stats` returns dims `([member|source,] stats, y_bin, x_bin)`, with `stats` ordered as `binning.STATS = ("mean", "var_pop", "var_samp", "count", "count_pos", "sum_w", "n_eff")` (`count`/`count_pos` raw sample counts; `sum_w` the sum of the weights and `n_eff` the Kish effective sample size, both = `count` when unweighted). The edges are stored in attrs and the per-bin lower/upper/center coords. Sensitivity runs (other bin counts, weighting, ...) coexist because each has its own run ID in the folder and file names (e.g. `<family>.et.qbin_pooled_all.<run_id>.nc`).
- **Runs:** a run is the defaults of `config/pipeline.yml` changed by an optional run file `config/runs/<name>.yml` (only the keys that differ; unknown keys and invalid values raise; a mapping inside a family, e.g. `prep.cmip.member_ids` or `prep.trendy.omit_models`, is replaced whole), selected with `ETUNC_RUN`. Its IDs are hashes of its settings (`etunc.config`): `PREP_ID` = "p" + 7 hex of `prep` (with every family's products, models and members, so changing one family's gives every family a new PREP_ID), `RUN_ID` = "r" + 7 hex of `prep` + `binning` (`plotting` and paths are not hashed), so the same settings always give the same IDs and runs differing only in `binning` share their prep inputs. `cfg.register_run()` adds the run to `config/runs.csv` (IDs, run file, time, git commit/branch, key settings, `settings_json`), the lookup from any ID to its settings. Importing `etunc.config` never writes. The ID of the defaults is `r183a58a` (prep `p2abea0a`) as long as `config/pipeline.yml` is unchanged (`r804f517`/`pcd00d67` before the family settings moved there).
- **Output folders:** every output is in `cfg.output_dir(root, family, kind, id)` = `<root>/<id>/<family>/<kind>/`, the same under `PROC_ROOT` and `FIG_ROOT`, and every file name ends in `.<id>.<ext>`. `id` is `cfg.PREP_ID` for what depends on the prep settings only (`inputs` of prep_*.py and bin_plumber.py, the prep `clim` figures and the plumber `clim`, `coverage` of diagnose_obs.py, `radiation` of compare_rn.py, `mask` of make_mask.py) and `cfg.RUN_ID` for everything from make_edges.py on (`mask`, `edges`, `qbin`, `regress`, `decomp`; make_edges.py and the analyses write as family `all`). Helpers: `cfg.inputs_path(family[, prep_id])`, `cfg.area_mask_path([run_id])`, `edges.edges_path(kind, variable[, run_id])`. Build output paths with these helpers, never by hand. File names carry no grid, period, bin counts or weighting (the run fixes them; `config/runs.csv` and the netCDF attrs record them).
- **Units:** there are two conversion paths. `convert_units` keys on the variable name (CMIP, CESM, ERA5), and `flux_to_wm2`/`latent_heat_to_wm2` key on the `units` attr (ILAMB); `accumulation_to_flux` converts totals (gridded obs). All use L = 2.45e6 J/kg.
- **Net radiation sign conventions** differ by source. Use the matching `net_radiation_cmip`, `net_radiation_cesm`, `net_radiation_clm` (offline CLM) or `net_radiation_era5`.
- **Domain:** `TIME_SLICE` (`prep.time_slice`, default 2001-2014) for every family, `LAT_BNDS = slice(-58, 90)` excludes Antarctica, Greenland/Iceland (AR6 region 0) are excluded, and the land fraction threshold is `LF_THRESH = 0.5`.
- **Tests:** all tests (in `tests/`) use synthetic data. `tests/test_temporal.py` covers `temporal` (annual means, climatologies, missing-month rules), `tests/test_binning.py` covers `units`, `binning`, `plotting`, the aridity index, and the grid checks, land masks and area masks, `tests/test_edges.py` covers the hierarchical weights and weighted edges, `tests/test_variants.py` covers the groups of variants and nested group means, `tests/test_regression.py` covers `regression` and `binning.between_bin_fraction`, `tests/test_decomposition.py` covers `decomposition` (the identities of the counterfactual means and terms, off-support mass, the state shift, pooling, obs product axes and weights, variance partitions, the gridded maps), `tests/test_config.py` covers `etunc.config` (settings and run files, validation, run IDs, `register_run`, `ETUNC_RUN`/`ETUNC_PATHS`; `tests/conftest.py` points the tests at `config/paths.example.yml`), `tests/test_grid.py` covers `etunc/grid.py` (including `cell_area`, `land_area`, `mask_to_land` and the regridding of steps 5-7), `tests/test_load_obs.py` and `tests/test_regrid_obs.py` cover the obs loader and regridder, and `tests/test_load_era5.py`, `tests/test_load_ilamb.py` and `tests/test_load_cmip.py` and `tests/test_load_trendy.py` pin the raw-loader contract and the CMIP member selection. Not tested, because they need glade data or PBS: the pipeline scripts, `etunc/load/cesm.py` and `etunc/dask_cluster.py`.
