# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Research code for quantifying evapotranspiration (ET) uncertainty. ET is binned in a 2-D space of climatological leaf area index (LAI, y-axis) and aridity index (AI = Rn / L·P, x-axis), so CMIP6 models, CESM ensembles (FHIST PPE "fppe", offline IHIST PPE "ippe", GOGA2, LENS2) and ILAMB observational products can be compared bin by bin.

Runs on NCAR's glade (Derecho/Casper). Data and outputs live outside the repo:
- Inputs: `/glade/campaign/univ/uwas0155/` (ILAMB and gridded obs, regridded obs and CMIP6). This is shared campaign storage, so don't write there unless asked.
- TRENDY (GCB2025) output and its forcing (`crujra3/`, `Radiation/`): `/glade/derecho/scratch/bbuchovecky/trendy/` (`TRENDY_ROOT`, purgeable scratch).
- CMIP6 catalogs: `/glade/derecho/scratch/bbuchovecky/cmip_intake_esgf_fetch/`. They, and about 2/3 of the file paths in `cmip_evap.csv`, are on purgeable Derecho scratch. Moving them only needs `CMIP_FETCH_ROOT` changed in `etunc/config.py`.
- Outputs: `/glade/work/bbuchovecky/et_unc/proc` (netCDF, `PROC_ROOT`) and `/glade/work/bbuchovecky/et_unc/fig` (figures, `FIG_ROOT`), both laid out as `<root>/<family>/<kind>/<period>/[<bins>/]` (see Output folders below); bin edges in `proc/qbin_edges/<period>/<bins>/`. The repo's `fig` is a symlink to `FIG_ROOT`, ignored by git, so figures are not tracked. Figures made for a collaborator are copied into the repo's `for/<person>/` (tracked, same `<family>/<kind>/<period>/[<bins>/]` layout, e.g. `for/aswann/obs/clim/199501-201412/`).
- Every path above is set in `etunc/config.py`.

## Commands

The Python env is the pixi env `etunc`, defined in `pyproject.toml` (`[tool.pixi.*]`, exact versions in `pixi.lock`) with the repo installed editable. It is detached to `/glade/work/bbuchovecky/pixi/envs/etunc-<hash>/envs/default`. Don't hardcode that path; use `pixi run` (pixi is at `~/.pixi/bin/pixi`). `pixi run` finds the manifest by searching up from the current directory, so outside the repo (e.g. PBS jobs) pass `--manifest-path <repo>/pyproject.toml`, as `scripts/run_logged.sh` does. Ad-hoc commands (`pixi run python ...`) run in the caller's directory, while defined tasks (`pixi run test`, `prep-obs`, …) run in the repo root. Every `pixi run` first checks the env against `pixi.lock`: if the manifest was edited, it re-solves, rewrites `pixi.lock` and updates the env before running. Use `--frozen` (install the lock as-is) or `--locked` (fail if the lock is stale) to prevent that. Dependencies are changed with `pixi add` or by editing the manifest, and the updated `pixi.lock` is committed with them. The env has xarray, xesmf, regionmask, cartopy and dask-jobqueue, but not ILAMB (`etunc.grid.cell_area` is a bit-identical port of `ilamblib.CellAreas`). The notebooks run on the `etunc` Jupyter kernel, except `notebooks/check-disalexi.ipynb` (`openet` env, `envs/openet.yml`). The repo is self-contained: don't add dependencies on the user's other packages (e.g. xclimate) or on modules from their other projects.

The scripts in `scripts/` take no CLI arguments and import only the `etunc` package, never each other. They are configured by module-level constants at the top of each file (`ILAMB_PRODUCTS`, `GRIDDED_ET_PRODUCTS`, `SOURCE_IDS`, `MEMBER_IDS`, `MEMBERS`, `BIN_FAMILIES`, …); settings shared by every family (`TIME_SLICE`, `TARGET_RES`, `MIN_YEARS`, `MIN_ANNUAL_ET`, `FAMILIES`, `N_XBINS`/`N_YBINS`) are in `etunc.config`. `BIN_VARIABLE`, `AREA_WEIGHTED`, `N_XBINS` and `N_YBINS` take environment overrides `ETUNC_<NAME>` (used by `run_all.sh`). Each `main()` starts with `cfg.summarize()` and `cfg.summarize_settings(globals())`, so the log records every setting. Output folders come from `etunc.config`. The download scripts are in `scripts/download/`.

## Architecture

Layout: `etunc/` (library), `etunc/legacy/` (unmaintained code), `scripts/` (runnable pipelines; `scripts/download/`, `scripts/legacy_regrid/`), `docs/binning-workflow.md` (the pipeline step by step), `notebooks/`, `tests/`, `envs/` (conda envs outside pixi: `openet`, `lftp`), `for/` (figures shared with collaborators), `fig` (symlink to `FIG_ROOT`, untracked). README.md has a table of the modules.

**The binning pipeline** is documented step by step in `docs/binning-workflow.md`, and every family runs the same numbered steps, written out in the script's `main()` as one or two calls per step to small single-purpose library functions (no wrapper hides several steps):
- `scripts/prep_{obs,era5,cmip,lens,fppe,ippe}.py`, steps 1-11: (1-2) raw monthly native fields over `TIME_SLICE`; (3) ET, P, Rn to W/m2; (4) annual means over complete years (`temporal.aggregate(da, "year")`: ET/P/Rn need 12 valid months, a missing LAI month counts as 0); (5) native land mask without Greenland/Iceland (`grid.mask_to_land` with `landne_mask` for ILAMB and gridded obs (also the LAI of prep_era5), `landfrac_mask` of LANDFRAC/sftlf for ERA5, CMIP6 and CESM); (6) ET outlier filter `binning.drop_et_outliers` (annual ET < `MIN_ANNUAL_ET`); (7) conservative regridding (`bounded_conservative_regridder`, `regrid_with_na_thresh` with `NA_THRESH`, `on_grid`); (8) `LAT_BNDS`; (9) complete years shared by the four products (`temporal.shared_years`, ≥ `MIN_YEARS`); (10) climatological LAI, P, Rn over those years (`temporal.aggregate(da, "clim")`); (11) AI = Rn/P (`edges.compute_aridity_index`). Saved as `PROC_ROOT/<family>/inputs/<period>/<family>.inputs.<grid>.<period>.nc` (`cfg.inputs_path`): `et (member, year, lat, lon)`, `lai`, `pr`, `rn`, `ai (member, lat, lon)`, with a `source` coord on `member`. A source is an obs (ET, LAI, P, Rn) product combination of ILAMB and gridded products (prep_obs; with `<v>_product`, `n_years`, `time_period` coords), ERA5 ET, P and Rn with the ILAMB LAI `LAI_PRODUCT` (prep_era5; one source, `lai_product` coord), a CMIP6 model (prep_cmip; member = "<source_id>.<member_id>", `member_id` coord; `DEFAULT_MEMBERS = "top"` is one member per model), a LENS2/FHIST PPE/IHIST PPE member, or a TRENDY model (prep_trendy; one member per model). The scripts differ only in steps 1, 3 and 5 (prep_ippe: offline CLM, so P = RAIN + SNOW and Rn = FSA - FIRA from "lnd"). With `BIN_VARIABLE = "et_pr"` (default `cfg.BIN_VARIABLE = "et"`), step 11b also saves the annual evaporation ratio `et_pr (member, year, lat, lon)` (`binning.evaporation_ratio`), which the bin scripts then bin instead of ET (outputs `<family>.et_pr[_clim].qbin_*`).
- `scripts/prep_trendy.py`, steps 1-11 for the TRENDY DGVMs of one `EXPERIMENT` (S2: climate + CO2, S3: + land use change), saved as the family `trendy_s2`/`trendy_s3`: ET is `evapotrans`, P is the CRU-JRA precipitation forcing and Rn the ERA5 net radiation (`msnswrf + msnlwrf`, ERA5 LANDFRAC mask), each one field for every model (steps 1-8 run once before the model loop), so the AI is the same for every model; Natural Earth land mask for the model fields, LAI NaN on land set to 0, `OMIT_MODELS` (CARDAMOM: 2003-2024 only; LPJml, LPJwsl, LPX-Bern, VISIT: implausible LAI). TRENDY is not yet in `cfg.FAMILIES` or `run_all.sh`.
- `scripts/make_edges.py`, steps 12-13: each family's own valid area (`grid.valid_area`) and their intersection (`grid.common_area`, which reports the gridcells and km2 each family loses), saved at `cfg.area_mask_path`; LAI/AI quantile edges on the common area, "pooled_all" with hierarchical weights (`edges.hierarchical_weights`: each family, each source within a family and each member within a source weighs equally) and "pooled_<family>", saved at `edges.edges_path`. Weighted quantiles use `np.quantile(weights=, method="inverted_cdf")`.
- `scripts/bin_all.py`, step 14: for every family in `BIN_FAMILIES`, `binning.bin_stats(member_dim="member", mask=common area)` with both edge sets, per member and with each source's members pooled; with `cfg.AREA_WEIGHTED`, the bin statistics are weighted by each gridcell's land area (`bin_stats(weights=grid.land_area)`, outputs tagged `.area_weighted`, same edges); family-specific outputs (obs spread across ET products, LENS2 members pooled) in a labelled section.
- `scripts/bin_all_clim.py`, step 14 with climatological ET: as `bin_all.py`, but each member's ET is first averaged over `year` (`temporal.aggregate(et, "clim")`, NaN years skipped), so each gridcell is one sample. Outputs are named `<family>.et_clim[.area_weighted].qbin_*`.
- `scripts/bin_area.py`, step 14 for land area: each gridcell of the common area, binned by its member's climatological LAI and AI, with its land area as the value (`grid.land_area`: target-grid cell area times fractional Natural Earth land, one field for every family, since obs have no land fraction). Bin total = `mean` x `count` of `bin_stats`; sources average their members. Outputs `<family>.land_area.qbin_*` (`land_area` km2, `land_area_frac`, `n_cells`).

**Analyses outside the pipeline**, run by hand after step 14 (not by `scripts/run_all.sh`):
- `scripts/diagnose_obs.py`: coverage of every obs product of ET, LAI, P and Rn (ILAMB, the gridded ET products and CLARA-A3 Rn), each variable with the same diagnostics (`docs/obs-availability.md`): land area covered on the native and target grids, native coverage maps (valid months, valid years under the step 4 rule, seasonal gaps), valid land fraction by latitude, regional timeseries, target-grid climatologies with the differences of every pair of products (steps 4-8 and 10 of prep_obs.py), and land-area weighted histograms with `QUANTILES`. Each product is read once and reduced lazily, so 0.1 deg records are never held in memory. Outputs in `FIG_ROOT/obs/coverage/<period>/` and a CSV per variable in `PROC_ROOT/obs/coverage/<period>/`.
- `scripts/compare_rn.py`: the evidence for the Rn of prep_trendy.py. Downward shortwave (ERA5 `msdwswrf`, CERES `rsds`, CRU-JRA as the median `rsds` of `RSDS_MODELS`, since `crujra3/` has no shortwave), downward longwave (ERA5, CERES `rlds`, CRU-JRA `dlwrf`) and Rn (ERA5, CERES), each through steps 4-8 and 10 on Natural Earth land; every pair compared by band (bias, RMSE, pattern r) and by the interannual r of the land means. Outputs in `PROC_ROOT/trendy/radiation/<period>/` (CSV, climatologies) and `FIG_ROOT/trendy/radiation/<period>/`.
- `scripts/regress_lai_aridity.py`: per member, OLS of ET on climatological LAI and AI (`regression.lai_ai_regression`: R² of ET ~ LAI, ~ AI, ~ LAI + AI and its unique/shared partition) on the samples of `bin_all.py` and `bin_all_clim.py`, with the η² of the bins (`binning.between_bin_fraction`) for comparison. Saved at `PROC_ROOT/<family>/regress/<period>/<bins>/`.

**Load modules are as simple as possible:** each `load_native` does step 1 only and returns raw monthly fields on the native grid, in native units, with lon in [-180, 180] and lat ascending (`format_grid`): `il.load_native(variable, product, time_slice)` (DataArray, fill values NaN), `le.load_native(codes, time_slice)` ({code: DataArray}), `cmip.load_native(loader, sid, members, time_slice, variables=, experiment_id=)` ({variable: (member, time, lat, lon)} with `member_id`), `lc.load_native("lens"|"fppe"|"ippe", members, time_slice, variables={CESM variable: gcomp})`. `lt.load_native(model, experiment, time_slice, variables)` ({variable: (time, lat, lon)}, TRENDY; every time axis is rebuilt as monthly ending in Dec 2024, `lt.LAST_MONTH`), and `lt.load_forcing(variable, time_slice)` (6-hourly forcing shared by every model, as monthly values: `lt.FORCING` lists `pre` (CRU-JRA precipitation, summed to mm/month), `dlwrf` (CRU-JRA downward longwave) and `fd` (`Radiation/` diffuse fraction of the downward shortwave), the latter two averaged). The gridded obs products are read with `lo.load_obs` (lazy, per-year files). `le/cmip/lc.load_land_fraction` return (land fraction [0-1], native grid with cell edges). Monthly regridded loaders for `make_mask.py` and `obs_et_availability.py`: `il.load_ilamb`, `lo.load_obs_regridded`.

**`etunc.load.cmip.CMIPESGFLoader`** reads a catalog CSV produced by the external `cmip-intake-esgf-fetch` tool. It handles model, member and variable availability and loading; model and member selection for `prep_cmip.py` is `cmip.available_members`/`select_members`/`sftlf_files`.

**`etunc/grid.py`** (imported as `rg`) holds the shared regridding utilities. `rg.target_grid(res)` is the only source of target grids: the two standard ones, 0.5° and 1° (`rg.RESOLUTIONS`, named by `rg.grid_tag`), and any other spacing that divides 180. All are global, lon in [-180, 180], lat ascending, with `lat_b`/`lon_b` edges. Never build a target grid by hand. Regridders: `conservative_regridder` (cached, regular 1-D sources), `bounded_conservative_regridder` (cached, any 1-D source such as Gaussian grids, edges from CF bounds or midpoints), `make_regridder` (any method). `regrid_with_na_thresh` applies a conservative regridder skipping NaN and keeps coords such as `member_id`; `on_grid` snaps to the exact target coords (it no longer cuts `LAT_BNDS`).

**`etunc/load/obs.py`** (imported as `lo`) loads gridded obs products (ET: GLEAM v4.3, PML-V2.2, SiTHv2; radiation: CLARA-A3 "clara", not yet used by prep_obs.py since its shortwave is missing in low-sun months; all in `/glade/campaign/univ/uwas0155/obs/`) into one lazy DataArray with `load_obs(dataset, var, time_slice, version=, freq=)`. `load_obs_regridded(dataset, var, time_slice, res)` conservatively regrids each time step in memory. Each product is an `ObsDataset` entry (path template, versions, frequencies, coord names), so a new product is added with `register_dataset`. Monthly and yearly ET files hold totals (mm/month, mm/year); `etunc.units.accumulation_to_flux` converts them to kg m-2 s-1. CLARA-A3 files hold monthly mean fluxes (W m-2). **`etunc/load/cesm.py`** (`lc`) loads the CESM2 ensembles from the tseries archives (`load_ppe("fppe"|"ippe", ...)`, members in parallel threads; `load_cesm2le`; `load_grid`; `ppe_member_name`). **`etunc/load/era5.py`** (`le`) loads ERA5 monthly means from GDEX and the ERA5 grid file. **`etunc/dask_cluster.py`** (`dc`) starts and stops a PBS dask cluster on Casper or Derecho for the notebooks.

**`etunc/legacy/`** holds unmaintained, untested code that the pipeline no longer uses, one module per origin: `notebook` (the former `etunc/legacy.py`), `binning`/`grid`/`temporal`/`plotting` (replaced functions, e.g. `prepare_inputs`, `regrid_annual`, the unweighted `pooled_bin_edges`), and `load_{ilamb,obs,era5,cmip,cesm}` (the former annual `load_native`/`load_annual`, `load_goga2`, `regrid_to_target`, `regrid_file`, `LegacyCMIPESGFLoader`). Notebooks and `scripts/legacy_regrid/` import from it. Code that maintained scripts stop using moves there instead of being deleted.

**Notebooks** (`notebooks/`) are exploratory and analysis work. Each starts with a cell naming its env. They were not updated for the restructure: they read outputs of the former `bin_*.py` scripts and may use functions now in `etunc.legacy`. `pooled-edges-all.ipynb` was the prototype of `make_edges.py`.

## Conventions that matter

- **Binning semantics:** every (year, gridcell) annual-mean ET sample is binned by that gridcell's climatological LAI and AI of the same member (`bin_all_clim.py`: one climatological ET sample per gridcell). `bin_stats` broadcasts the (lat, lon) LAI and AI fields over `year` (and `member`).
- **Grid alignment:** inputs must share coordinates exactly. `bin_stats` uses `xr.align(join="exact")` and `check_same_grid` raises an error instead of reindexing silently; `mask_to_land` checks the land mask's grid.
- **Evaporation ratio (`BIN_VARIABLE = "et_pr"`):** annual ET_y / P_y with the same year, product and source of P as the AI's P (each obs combination's own P product); NaN where P <= 0. The clim variant (`bin_*_clim.py`) is the mean of the annual ratios. PLUMBER2 towers use the annual P of each product set's `pr_product` over `TIME_SLICE` (`bin_plumber.py`). Edges and common area mask are those of ET.
- **Duplicate quantile edges** (from many LAI = 0 values) are kept on purpose. `searchsorted(side="right")` puts tied values in the *last* duplicate bin, which leaves zero-width empty bins that `drop_zero_width_bins` removes. Out-of-range values are clipped into the edge bins.
- **Output layout:** `bin_stats` returns dims `([member|source,] stats, y_bin, x_bin)`, with `stats` ordered as `binning.STATS = ("mean", "var_pop", "var_samp", "count", "count_pos", "sum_w", "n_eff")` (`count`/`count_pos` raw sample counts; `sum_w` the sum of the weights and `n_eff` the Kish effective sample size, both = `count` when unweighted). The edges are stored in attrs and the per-bin lower/upper/center coords. File names carry the bin counts so sensitivity runs can coexist: edges `<n>_quantiles`, and step 14 and regression outputs `lai<N_YBINS>_ai<N_XBINS>` (e.g. `<family>.et.qbin_pooled_all.lai15_ai15.<grid>.<period>.nc`).
- **Output folders:** every output is in `cfg.output_dir(root, family, kind, period[, bins])` = `<root>/<family>/<kind>/<period>/[<bins>/]`, the same under `PROC_ROOT` and `FIG_ROOT`: `kind` is `inputs`, `clim`, `mask`, `qbin`, `regress`, `coverage` (diagnose_obs.py) or `radiation` (compare_rn.py), `period` the `YYYYMM-YYYYMM` of `TIME_SLICE`, `bins` = `cfg.bins_tag(N_YBINS, N_XBINS)` ("lai15_ai15", `qbin` and `regress` only). make_edges.py writes as family `all`; edges are in `BIN_EDGES_ROOT/<period>/<bins>/` (`edges.edges_path(kind, variable, n_ybins, n_xbins, grid, period)`). Build output paths with these helpers, never by hand. File names keep the grid, period and bin counts.
- **Units:** there are two conversion paths. `convert_units` keys on the variable name (CMIP, CESM, ERA5), and `flux_to_wm2`/`latent_heat_to_wm2` key on the `units` attr (ILAMB); `accumulation_to_flux` converts totals (gridded obs). All use L = 2.45e6 J/kg.
- **Net radiation sign conventions** differ by source. Use the matching `net_radiation_cmip`, `net_radiation_cesm`, `net_radiation_clm` (offline CLM) or `net_radiation_era5`.
- **Domain:** `TIME_SLICE` 1995-2014 for every family, `LAT_BNDS = slice(-58, 90)` excludes Antarctica, Greenland/Iceland (AR6 region 0) are excluded, and the land fraction threshold is `LF_THRESH = 0.5`.
- **Tests:** all tests (in `tests/`) use synthetic data. `tests/test_temporal.py` covers `temporal` (annual means, climatologies, missing-month rules), `tests/test_binning.py` covers `units`, `binning`, `plotting`, the aridity index, and the grid checks, land masks and area masks, `tests/test_edges.py` covers the hierarchical weights and weighted edges, `tests/test_regression.py` covers `regression` and `binning.between_bin_fraction`, `tests/test_config.py` covers the `ETUNC_*` environment overrides of `etunc.config`, `tests/test_grid.py` covers `etunc/grid.py` (including `cell_area`, `land_area`, `mask_to_land` and the regridding of steps 5-7), `tests/test_load_obs.py` and `tests/test_regrid_obs.py` cover the obs loader and regridder, and `tests/test_load_era5.py`, `tests/test_load_ilamb.py` and `tests/test_load_cmip.py` and `tests/test_load_trendy.py` pin the raw-loader contract and the CMIP member selection. Not tested, because they need glade data or PBS: the pipeline scripts, `etunc/load/cesm.py`, `etunc/dask_cluster.py`, and `etunc/legacy/` (unmaintained).

## Code Structure and Abstraction
- This project is scientific, not software engineering. The code should always prioritize readability over abstraction, so that any scientist can easily understand the key assumptions and decisions in the analysis pipeline from loading to preprocessing to binning. Ideally, this pipeline should be made clear in the binning scripts.
- Simplicity is very important.
